# Карта Танфера

Вероятностное наложение литературного Танфера на современную карту Сент-Луиса. Откройте `index.html`.

Подложка: © OpenStreetMap contributors, ODbL. Библиотека: Leaflet 1.9.4.

Проект использует только аналитические заметки и собственную графику. Тексты романов и предоставленный рабочий PDF не публикуются.
